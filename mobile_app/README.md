# Task Bandhu Apex — Mobile Application (Flutter & Dart)

The official cross-platform iOS & Android mobile application for **Task Bandhu Apex**, built with liquid glassmorphism, adaptive platform design, ambient focus audio, and encrypted video/audio huddles.

---

## 🌟 Super-App Highlights

1. **Pixel-Perfect Liquid Glassmorphism**:
   - **Light Mode**: Pastel lavender & peach mesh gradient with translucent frosted glass cards.
   - **Dark Mode**: Deep midnight luxury with neon glow accent borders and dark glass elevation.
2. **Platform-Adaptive Brand Feel**:
   - **iOS**: Cupertino navigation, frosted action drawers, and Dynamic Island layout.
   - **Android**: Material 3 fluid curves, floating action pills, and haptic feedback.
3. **Core Parity with Web App**:
   - Top-level **[ 🔒 Personal | 👥 Team ]** Workspace Switcher.
   - Smart lists: **My Day**, **Task Schedule** (horizontal week picker), and **All Tasks**.
   - Interactive **STEPS** checklist on task cards.
   - **Team Projects & Team Chat Room** with real-time messages and Owner badges.
4. **Super-App Multi-Utility**:
   - **Ambient Lo-Fi & Focus Music Player**: Lo-Fi beats, Rain on Skylight, Cafe Ambience, and 432Hz Binaural Waves.
   - **Encrypted Video & Audio Huddle**: Instant team meet room with participant video grid, mute/cam controls, and call timer.
   - **Daily Wellness & Activity Rings**: Track Focus hours, Tasks completed, and 7-Day Streaks.

## 🚀 Quick Start Guide

### 1. Requirements
- Flutter SDK (3.0.0 or higher) & Dart SDK
- Android Studio / VS Code (with Flutter extension) or Xcode (for iOS)

### 2. Run the App
```bash
cd mobile_app
flutter pub get
flutter run
```

### 3. Build Release APK (Android)
```bash
flutter build apk --release
```
Output will be generated in `build/app/outputs/flutter-apk/app-release.apk`.
