# 🚀 Task Bandhu - Personal Productivity OS

Task Bandhu is a high-performance, real-time productivity workspace designed to help users track tasks, maintain focus, and build consistency. Built as a seamless cross-platform SaaS alternative.

## ✨ Enterprise-Grade Features

*   **🔒 Secure Partitioning:** Forced Google Authentication ensures 100% isolated user subcollections via Firebase Firestore.
*   **🧠 AI Task Breakdown:** Context-aware AI automatically generates actionable sub-steps based on task titles (e.g., coding vs. studying).
*   **🎧 Deep Focus Mode:** Native Pomodoro timer featuring Web Audio API Brown Noise generation, Wake Lock, and anti-distraction tab-switching alerts.
*   **📈 Gamification Engine:** Mathematical daily streak calculation, XP tracking, and dynamic leveling.
*   **🛹 Native Kanban Board:** Fluid HTML5 drag-and-drop between Pending and Completed states.
*   **💽 Data Portability:** 1-click JSON bulk export and strictly validated JSON import for cloud restoration.
*   **📱 101% Responsive:** Fluid UI scaling perfectly from desktop to mobile screens.

## 🛠️ Tech Stack
*   **Frontend:** React 18, Vite, Tailwind CSS, Lucide-React
*   **Backend & DB:** Firebase Authentication (Google Provider), Firebase Firestore (NoSQL)
*   **Native APIs:** Web Audio API (Synthesizer), Wake Lock API, HTML5 Drag & Drop
